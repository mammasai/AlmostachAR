# AlmostachAR (المستشار)

وكيل ذكاء اصطناعي لهندسة معالجة اللغة العربية الطبيعية.

## نظرة عامة

AlmostachAR منصة تفاعلية تعتمد على نظام متعدد الوكلاء (Multi-Agent System)، تعمل كمستشار يرافق مهندسي البيانات والباحثين في بناء نماذج الذكاء الاصطناعي العربية، من فحص البيانات الخام وحتى تقييم النموذج المدرَّب.

المشروع يجمع بين خمسة وكلاء متخصصين تحت إشراف وكيل مدير (Orchestrator)، يفهم طلب المستخدم بلغة طبيعية عبر واجهة محادثة، ويوجّه الطلب تلقائياً للخبير المناسب.

## البنية العامة

المستخدم يكتب رسالة في واجهة المحادثة، فيتلقاها وكيل المدير الذي يفهم القصد ويقرر أي خبير من الخمسة يستدعي: محللة جودة البيانات، أخصائية المعالجة، مستشارة النماذج، مهندسة التدريب، أو محللة الأداء.

 # الوكلاء

| الوكيل | الملف | الوظيفة |
|---|---|---|
| المدير | `agents/orchestrator.py` | يفهم رسائل المستخدم ويوجّهها للخبير المناسب |
| محللة جودة البيانات | `agents/data_inspector.py` | فحص الترميز، توزيع الكلمات، كثافة المفردات |
| أخصائية المعالجة | `agents/preprocessor.py` | تطبيع النصوص، إزالة التكرار، التعامل مع التشكيل |
| مستشارة النماذج | `agents/model_advisor.py` | اقتراح أنسب نموذج (AraBERT / CAMeLBERT / MarBERT) |
| مهندسة التدريب | `agents/trainer.py` | تقسيم البيانات وتوليد سكريبت تدريب جاهز |
| محللة الأداء | `agents/evaluator.py` | حساب مقاييس التقييم وتحليل الأخطاء |

## التقنيات المستخدمة

- CrewAI لإطار عمل الوكلاء المتعددين
- Groq API (Llama-3.3-70b-versatile) كنموذج لغوي أساسي
- CAMeL Tools لمعالجة اللغة العربية
- Hugging Face Transformers للنماذج العربية المُدرَّبة مسبقاً
- Streamlit لواجهة المحادثة
- scikit-learn لمقاييس التقييم
